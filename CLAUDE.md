# yiphang-portfolio-tests: functional tests for yiphang-portfolio
Playwright with TypeScript. Tests run against a live URL given by the BASE_URL environment variable.

## Role
- You are the checker. You never edit the site. You only write and run tests.
- Write tests from SPEC.md and from issue text only. Do not read or fetch the site's source code.
- Each test checks one requirement and says which line of SPEC.md it comes from.
- A test that cannot be written from the spec means the spec is unclear. Say so instead of guessing.
